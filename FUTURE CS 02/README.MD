# Phishing Email Detection & Awareness System

## 📌 Project Overview
This project was completed as part of the Future Interns Cyber Security Internship (Task 2). The objective is to analyze phishing emails, identify phishing indicators, classify email risks, and create user awareness to help prevent phishing attacks.

## 🎯 Objective
- Analyze phishing email samples
- Identify phishing indicators
- Classify email risk
- Explain phishing attacks in simple language
- Create awareness and prevention guidelines

## 🛠️ Tools Used
- Google Message Header Analyzer
- MXToolbox Email Header Analyzer
- Web Browser
- Canva
- GitHub

## 🔍 Analysis Process
1. Collected phishing email sample
2. Examined sender information
3. Inspected URLs and email content
4. Identified phishing indicators
5. Classified the email risk
6. Documented findings
7. Prepared user awareness guidelines

## 🚩 Phishing Indicators Identified
- Suspicious sender email/domain
- Urgent and fear-based language
- Suspicious URL
- Generic greeting
- Request for immediate action

## ⚠️ Risk Classification
**Risk Level:** High

**Status:** Phishing Email

## 🛡️ Prevention Tips
- Verify the sender before responding.
- Never click suspicious links.
- Check URLs carefully.
- Do not share passwords or OTPs.
- Report suspicious emails to the security team.
